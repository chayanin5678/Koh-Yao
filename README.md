# KohYao system fixes

ชุดไฟล์ระบบที่แก้ไขจากการทดสอบวันที่ 29 ตุลาคม 2026 โดยเก็บโครงสร้าง `kohyaosunsmile.com/public_html/` เดิมไว้

Repository นี้เป็นชุดไฟล์แก้ไข 80 ไฟล์ ไม่ใช่เว็บไซต์ทั้งชุด ต้องใช้ร่วมกับซอร์สและ assets เดิม ไม่มี SQL dump ข้อมูลลูกค้า uploads หรือข้อมูลทดสอบในเครื่อง

## การตั้งค่าฐานข้อมูล

สำเนาที่เผยแพร่ไม่มีชื่อบัญชีหรือรหัสผ่านฐานข้อมูลเดิม กำหนด `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME` และ `DB_CHARSET` ผ่าน environment variables ก่อนใช้งาน ค่าเริ่มต้นของ user/password/database ใน `manageadmin/libs/connect.php` ถูกเว้นว่างโดยตั้งใจ

## ผลตรวจ

- PHP 8.3.26: lint ผ่าน 2,587 จาก 2,589 ไฟล์ของโปรเจกต์ต้นฉบับ รวมไฟล์ PHP ที่แก้ทั้ง 79 ไฟล์
- HTTP smoke test ผ่าน 12 รายการ
- Booking regression ผ่าน 5 รายการ รวมการค้นหา วันที่ ยอดรวม ฟอร์มผู้โดยสาร และ HTTP 503 เมื่อฐานข้อมูลไม่พร้อม
- ยังเหลือเทมเพลตเก่า 2 ไฟล์ที่ parse ไม่ผ่านและไม่ได้รวมในชุดแก้ไข
- ยังไม่ได้ทดสอบชำระเงินจริง ส่งการจองจนจบ อีเมล LINE หรือสิทธิ์แอดมินครบทุกกรณี

ดูรายละเอียดและข้อจำกัดใน `reports/TEST-REPORT-DETAILED.md` หลังอัปชุดไฟล์แก้ไข สำรองระบบและทดสอบใน staging ก่อนนำไปใช้งานจริง
