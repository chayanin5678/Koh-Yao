# KohYao system fixes

ชุดไฟล์ระบบที่แก้ไขจากการทดสอบวันที่ 29 ตุลาคม 2026 รวม 80 ไฟล์ตามโครงสร้างเดิม เป็นชุดแก้ไขสำหรับใช้ร่วมกับเว็บไซต์เดิม ไม่ใช่เว็บไซต์ทั้งชุด

## สิ่งที่แก้

- การเชื่อมต่อฐานข้อมูลรองรับ environment variables และจัดการข้อผิดพลาดอย่างเหมาะสม
- แก้ไวยากรณ์ไลบรารีเก่าให้ผ่าน PHP 8.3 lint
- นำสคริปต์แปลกปลอมที่ตรวจพบออก
- แก้รูปแบบวันที่ ปฏิทิน วันที่ในรายละเอียดการจอง ลำดับ JavaScript และ path รูปเที่ยวเรือ

## การตั้งค่า

กำหนด DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME และ DB_CHARSET ตามสภาพแวดล้อมของคุณ สำเนาที่เผยแพร่เว้นค่าบัญชี รหัสผ่าน และชื่อฐานข้อมูลไว้โดยตั้งใจ ไม่มี SQL dump ข้อมูลลูกค้า uploads หรือค่าการเชื่อมต่อทดสอบ

## ผลตรวจและขอบเขต

- ตรวจไวยากรณ์ไฟล์ PHP ที่เปลี่ยนแปลงทั้ง 79 ไฟล์ผ่าน
- HTTP smoke test ผ่าน 12 รายการ
- Booking regression ผ่าน 5 รายการ ครอบคลุมการค้นหา วันที่ ยอดรวม การโหลดฟอร์ม และการตอบเมื่อฐานข้อมูลไม่พร้อม
- ยังมีเทมเพลตเก่า 2 ไฟล์นอกชุดแก้ไขที่ parse ไม่ผ่าน
- ยังไม่ได้ยืนยันชำระเงินจริง การจองครบวงจร อีเมล LINE สิทธิ์แอดมิน หรือ runtime ของ Excel/PDF ครบทุกกรณี

สำรองระบบและทดสอบบน staging ก่อนใช้งานจริง การเปลี่ยนแปลงนี้ยังไม่ได้ deploy ไปยังเว็บไซต์จริง รายงานฉบับภายในไม่ได้รวมไว้ใน repository สาธารณะ
